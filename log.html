出発日

Google タイムライン読み込み

Googleマップ → プロフィール → 設定 → 個人的なコンテンツ → タイムラインをエクスポート で出したJSONを選ぶと、実際に走ったルートを地図に描きます。

読み込んだデータは端末の中だけに保存されます。どこにも送信しません。

書き出し

ログ（写真込み）をJSONで保存。機種変えても復元できます。

RIDES MAP 用ルート

実走ルートを index.html の path に貼れる形に間引いて出力します。旅のあと、第4回の記録を実ルートに差し替える用。

全消去

ログ・写真・ルートを全部消します。戻せません。
